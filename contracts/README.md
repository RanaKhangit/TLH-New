# TLH Contracts (M1)

## Setup
From repo root:

```bash
cd contracts
forge --version
forge build
forge test
```

## Structure

- `src/interfaces/` — shared interfaces
- `src/base/` — base contracts
- `src/shared/` — shared anchor chain contracts
- `src/trust/` — trust private chain contracts
- `test/` — Foundry tests
- `docs/adr/` — Architecture Decision Records
