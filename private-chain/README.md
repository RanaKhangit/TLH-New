# TLH Private Trust Chain

A 4-validator Polygon Edge IBFT 2.0 network providing a dedicated trust-chain environment separate from the Sepolia shared anchor deployment.

## Architecture

```
Shared Anchor Chain (Sepolia 11155111)     Trust Private Chain (Polygon Edge 100100)
┌──────────────────────────────────┐       ┌──────────────────────────────────┐
│  DIDRegistry           (proxy)   │       │  CredentialRegistry      (proxy) │
│  VCHashAnchors         (proxy)   │       │  TrustAttestationVerifier        │
│  AttestationVerifier   (proxy)   │       │                          (proxy) │
│  TLHCCIPReceiver       (proxy)   │ CCIP  │  TLHCCIPSender           (proxy) │
│              ◄───────────────────┼─bridge─┤                                 │
└──────────────────────────────────┘       └──────────────────────────────────┘
     Public provenance                        Private operational state
     (hashes, DIDs)                           (credential validity)
```

## Chain Configuration

| Parameter       | Value                  |
|-----------------|------------------------|
| Chain ID        | `100100`               |
| Consensus       | IBFT 2.0 (PoA)        |
| Validators      | 4                      |
| BFT Tolerance   | 3f+1 (1 faulty node)  |
| Block Time      | ~2 seconds             |
| Block Gas Limit | 20,000,000             |
| JSON-RPC        | `http://localhost:8545`|

## Prerequisites

- Docker and Docker Compose
- Foundry (forge, cast)
- Bash shell

## Quick Start

```bash
# 1. Initialise validator secrets and genesis
./scripts/init.sh

# 2. Start the 4-validator network
docker compose up -d

# 3. Verify the chain is running
cast chain-id --rpc-url http://localhost:8545
# Expected: 100100

# 4. Configure environment
cp .env.example .env
# Edit .env with deployer key and admin address

# 5. Deploy trust contracts
./scripts/deploy-trust-contracts.sh

# 6. Validate deployment
./scripts/validate.sh
```

## Deployed Contracts

Only trust-layer contracts are deployed to the private chain:

| Contract                  | Purpose                           |
|---------------------------|-----------------------------------|
| `CredentialRegistry`      | Trust credential storage          |
| `TrustAttestationVerifier`| On-chain attestation verification |

Shared contracts (DIDRegistry, VCHashAnchors, AttestationVerifier) remain on Sepolia.

## Operations

### Stop the network
```bash
docker compose down
```

### Reset and reinitialise
```bash
docker compose down -v
rm -rf data/ genesis.json
./scripts/init.sh
docker compose up -d
```

### View validator logs
```bash
docker compose logs -f validator-1
```

## Deployment Manifest

After deployment, the manifest is written to `contracts/deployment-manifest.private-chain.json` with the same schema as the Sepolia manifest.
